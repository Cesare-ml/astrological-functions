## New normalization-only entrypoint

`normalizeLegacyTransitSnapshot({ chart, selectedBodyNames })` is a strict **input adapter**, **not a second transit aspect engine**. It accepts a selected subset of a `NatalChartResult v0.1.0-experimental` with *additional original chart zodiac metadata*:

- `chart.zodiac: {type:'TROPICAL'}`, or `{type:'SIDEREAL',ayanamsaId:'named-version'}`, **must already exist on the source chart**. PR #12's original fixture does not have it: those unmodified old fixtures **correctly fail** with `MISSING_ZODIAC`. The adapter cannot reconstruct the original coordinate convention from longitude numbers or silently label it tropical. An upstream migration must establish and persist the original zodiac first.
- Requires a real UTC instant, exact chart contract version, full chart engine/kernel/time provenance, explicit unique 1–32 selected names, and validated matching **per-selected-body** metadata declaring `EARTH / ECLIPTIC_OF_DATE / APPARENT`.
- Rejects selected bodies without own-map membership, mismatched IDs, nonfinite coordinates/speeds, or mixed correction/frame/kernel/time semantics. Unselected bodies are not used.
- Returns a frozen `TransitSnapshotNormalizationResult` containing the canonical `.snapshot` ready for `calculateTransitFacts`, ordered selected names, `status:'SOURCE_ASSERTED_NOT_INDEPENDENTLY_VERIFIED'`, and `LEGACY_SOURCE_NOT_INDEPENDENTLY_VERIFIED` warning.
- **Metadata assertions do not prove that a source truly was generated by a validated Rust/JPL ephemeris.** Consumers must preserve the returned status and warning when composing or showing results; passing `.snapshot` into `calculateTransitFacts` alone does not propagate source warnings automatically.

### Example

```js
import {normalizeLegacyTransitSnapshot} from 'astrological-functions/transits/legacy-normalize';
import {calculateTransitFacts} from 'astrological-functions/transits';

// Both source charts must explicitly retain the original zodiac and per-body metadata.
const natal = normalizeLegacyTransitSnapshot({
  chart: enrichedNatalChart, selectedBodyNames:['Sun','Moon']
});
const sky = normalizeLegacyTransitSnapshot({
  chart: enrichedSkyChart, selectedBodyNames:['Mars']
});
const facts = calculateTransitFacts({
  birthTimeKnown:true, natal:natal.snapshot, sky:sky.snapshot,
  aspectDefinitions:[{id:'conjunction',angleDeg:0,maxOrbDeg:3}]
});
// Pass natal.status, sky.status, and all normalizer warnings onward.
// This sample is NOT a verified ephemeris integration or a production example.
```
